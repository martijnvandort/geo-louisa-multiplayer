# Geo Louisa

Welcome to Louisa's World of knowledge, culture and fun.

Pick a region or a country, choose what to find, and play the map quiz in English or Dutch.

## Run locally

```bash
npm install
cp .env.example .env.local
npm run dev
```

The app starts at http://127.0.0.1:43123. Leave the values in `.env.local` blank to play on the free basemap.

Single player is the default. Choose Multiplayer in step 4 to host a game: you get a start time, a 6-character code, and a join link. A second browser on this computer can open the link, or enter the code and a name. Both browsers show the same countdown and the names as people join. The game starts at that time. No account is required.
